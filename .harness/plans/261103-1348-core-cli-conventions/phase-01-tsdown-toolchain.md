# Phase 01: tsdown toolchain migration

## Context

The scaffold builds with `tsc + tsc-alias` (`dist/main.js`), while decision 0002 and the reference
repo build one self-contained ESM bundle with tsdown. This phase swaps the build so later phases
land on the shipping toolchain.

## Requirements

- `cs` builds as one ESM bundle `dist/cli.mjs` with a `#!/usr/bin/env node` banner.
- Dependencies stay exact-pinned; no floating ranges.

## Files

| File | Action |
| ---- | ------ |
| `package.json` | add exact-pinned `commander@15.0.0`, `@clack/prompts@1.8.1` (deps); `tsdown@0.23.1` (devDep); remove `tsc-alias`, `tsx`; scripts: `build` → `tsdown`, `dev` → `tsdown --watch`; add `"bin": {"cs": "dist/cli.mjs"}`; add `"files": ["dist"]` |
| `tsdown.config.ts` | new — port from `/Users/tandm/Documents/jearax/npm/jss-devtools/tsdown.config.ts`, minus the hooks bundle define and `__HARNESS_HOOK_BUNDLE__`; keep `UNRESOLVED_IMPORT` as error; `alwaysBundle` from package.json deps |
| `scripts/package-info.mjs` | new — port from the reference (package facts read once) |
| `vitest.config.ts` | add `test.setupFiles` or globalSetup only if phase 03 needs it; alias `@/` → `src/` for tests |
| `pnpm-lock.yaml` | regenerated by `pnpm install` |

## Steps

1. Edit `package.json` (deps, scripts, bin, files).
2. Write `tsdown.config.ts` and `scripts/package-info.mjs` following the reference files.
3. `pnpm install`.
4. Delete `src/main.ts` is phase 02's job — this phase only touches toolchain; `build` may temporarily
   keep a `src/cli.ts` placeholder absent: if tsdown errors on the missing entry, keep the old build
   script working until phase 02 lands `src/cli.ts` (phases 01+02 land together).

## Validation

```bash
pnpm install
pnpm build   # writes dist/cli.mjs once src/cli.ts exists (phase 02); before that, lint/typecheck must still pass
```

## Risk & rollback

- tsdown is pre-1.0 — pin `0.23.1` exactly, never a range.
- `strictPeerDependencies` is on: if an install fails on a peer, read the real error; do not
  downgrade Node or add overrides without reporting.
- Rollback: `git checkout` of `package.json`, remove the two new files.
